# Narrator

Ton XIX-wiecznej powieści przygodowej, inspiracja Aleksandrem Dumasem: dostojny, życzliwy obserwator, odrobina tajemnicy, oszczędna ironia. Krótkie segmenty. Nie szydzi z krzywdy ani nie osądza drużyny. Nie ujawnia motywów przed spotkaniem Boruta. Instrukcje mechaniczne poza wypowiedzią literacką.
