# Quest Grammar Patterns

Patterns are scaffolds, not recipes.

- Discover → Investigate → Confront → Resolve
- Request → Acquire → Complication → Deliver / Redirect
- Infiltrate → Observe → Learn → Decide → Escape
- Escort / Protect → Disruption → Recovery → Changed objective
- Hunt → Track → Reinterpret target → Confront
- Negotiate → Gather leverage → Bargain → Commit → Consequence
- Explore → Environmental clue → Pattern recognition → Revelation
- Prepare → Execute plan → Plan fails → Improvise → Aftermath
